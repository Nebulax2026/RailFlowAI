# 공개 입력 점수 하한 검증 — 2026-09-18

## 결론

현재 공개 입력과 구현된 규칙에서는 **A = 40.6, B = 30, C = 25.2보다
낮은 해가 없다**. 단순한 장시간 탐색 실패가 아니라, 목표 점수 미만이라는
제약을 추가한 CP-SAT 모델의 `INFEASIBLE` 판정으로 확인했다.

기존 main의 세 CSV 결과를 다시 읽어 작업량·안전·점수를 검증했으며 모두
통과했다. 따라서 해당 모델에서는 달성 가능한 상한과 증명된 하한이 같다.
공식 실행형 validator를 사용한 검증이나 공식 최적성 인증은 아니다.

| 시나리오 / 모델 | 확인한 점수 상한 | 판정 | 생성·내보내기·탐색 시간 |
| --- | ---: | --- | ---: |
| A / main의 공동 점유 패턴 | 40.5 | INFEASIBLE | 1.60초 |
| A / 별도 위치별 공유 모델 | 40.5 | INFEASIBLE | 0.57초 |
| B / main 모델 | 29.9 | INFEASIBLE | 0.22초 |
| C / main 모델 | 25.1 | INFEASIBLE | 5.01초 |

원시 실행 시점의 시간이다. 점수는 정수 10배로 계산하므로 각각 406, 300,
252보다 작은 정수 비용을 허용했다. 따라서 40.55 같은 더 작은 해를 빠뜨린
검사가 아니다. 각 탐색은 seed 42, worker 1, 최대 60초였다.

## B와 C는 공간 공유 모델 없이도 하한을 설명할 수 있다

각 작업을 독립적으로 두고 계약 자원, 선행관계, 공간·버퍼 충돌을 모두
제거한 완화 문제를 별도로 계산했다. 제약을 제거해 얻은 비용은 원문제의
하한이다. 여기서도 활동당 주 1회, 표준 작업량 1, ECLO 작업량 1.5,
시작 가능 주와 날짜별 지연 비용은 유지한다. C는 활동당 ECLO 최대 2회만
유지하고 다른 작업과의 ECLO 창 연결도 제거한다.

### B: 최소 6회 ECLO → 30점

- **A036**: 22주부터 시작, 26주 말까지 완료해야 한다. 5주 안에 작업량
  7을 처리하려면 `5 + 0.5 × ECLO ≥ 7`, 즉 최소 4회 ECLO가 필요하다.
- **A059**: 14주부터 시작, 19주 말까지 완료해야 한다. 6주 안에 작업량
  7을 처리하려면 최소 2회 ECLO가 필요하다.
- ECLO 1회당 5점이므로 하한은 `(4 + 2) × 5 = 30`.
  공급을 추가해도 한 활동을 같은 주에 두 번 수행할 수 없으므로 이 하한을
  피할 수 없다. 기존 30점 일정은 추가 공급 벌점 없이 이 하한을 달성한다.

### C: 지연을 받아들이는 편이 더 저렴 → 25.2점

- **A036**: ECLO 없이 가장 빨리 끝내도 28주 말이며, 목표보다 14일 늦다.
  비용은 `14 × 1.3 = 18.2`. ECLO 2회로 1주를 줄여도
  `7 × 1.3 + 2 × 5 = 19.1`이어서 더 비싸다.
- **A059**: ECLO 없이 최소 7일 지연으로 7점. ECLO 2회로 날짜를 맞추면
  10점으로 더 비싸다.
- 합계 하한은 `18.2 + 7 = 25.2`. 기존 일정이 이 값을 달성한다.

위 두 하한은 공유 그룹을 선택하는 알고리즘과 무관하다. 같은 입력과
작업량·주별 접근·ECLO·날짜·점수 정의를 유지한다면 B/C를 더 낮출 수 없다.

## A의 증명 범위

main 모델뿐 아니라, 계약 밤과 위치별 공유를 별도로 배정하는 기존 Scenario A
모델에서도 40.6 미만은 불가능했다. main의 40.6점 일정의 활동별 비용은
A001 = 8.4, A036 = 18.2, A059 = 7, A075 = 7이다.

추가로 위치별 작업 공유 조합과 PM의 독점 폐쇄만 남기고 비-PM 버퍼,
계약 자원, 선행관계, 전체 공유 그룹의 일관성을 제거한 더 느슨한 모델을
풀었다. 이 완화 문제의 최적값은 **32.2**다. 이것은 필요한 제약을 생략한
하한이며, 유효한 32.2점 일정을 발견했다는 뜻이 아니다. CSV 제출 해로
저장하거나 성과로 집계하지 않았다.

두 실제 모델은 모두 내부 안전 정책에 따른 모델이다. 특히 main은 일관된
공동 점유 패턴을 사용하는 보수적인 모델이고, 별도 A 모델도 직접 공유
증거에 따른 버퍼 면제를 사용한다. 공식 validator가 없고 주최측 샘플과의
정책 차이가 남아 있으므로 **주최측의 모든 허용 배정에서도 A가 40.6보다
낮아질 수 없다고 확정하지는 않는다**. 규칙이 달라지면 다시 검증해야 한다.
